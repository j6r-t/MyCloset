# MyCloset

Personal, Android-only wardrobe app: photograph clothes, remove backgrounds on-device, build outfits, get color-harmony-based suggestions. Flutter, fully local (no backend, no login).

## Documentation

Read in this order:

1. [`docs/handoff.md`](docs/handoff.md) — what this project is, decisions log, constraints, what's out of scope
2. [`docs/design.md`](docs/design.md) — visual direction (editorial/lookbook), design system, screen specs
3. [`docs/userFlow.md`](docs/userFlow.md) — every user journey step by step
4. [`docs/backend.md`](docs/backend.md) — local logic: DB schema, image pipeline, color extraction, suggestion engine

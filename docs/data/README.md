# Wada palette data (source)

Raw data from https://espectro.dev/api — an open API exposing Sanzō Wada's *A Dictionary of Color Combinations* Volume 1: 159 colors (`colors.json`) and 348 combinations (`combinations.json`). Fetched 2026-11-09.

**Status: INTEGRATED (2026-11-09).** `assets/data/palettes.json` holds all 348 combinations in the engine's format (`wada-<id>` names). The manual-transcription task is obsolete.
